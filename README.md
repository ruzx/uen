# Уен — татарча өйрәнәбез

Простые игры на татарском языке для детей 3–6 лет. Статический сайт без сборки: работает на GitHub Pages,
устанавливается как приложение (PWA) и работает офлайн.

Первая игра — **«Әкият геройлары»** (сыйфатлар / прилагательные):
куркак куян · көчле аю · кечкенә бака · матур тычкан · хәйләкәр төлке · усал бүре.

- **📖 Өйрән** — карточки: ребёнок нажимает на героя, слышит фразу, а герой «показывает» прилагательное
  (трусливый дрожит, сильный надувается, маленький уменьшается, хитрая крадётся, злой сердится, красивая сияет).
- **🎯 Тап!** — звучит фраза, нужно выбрать картинку из 4. Звезда — за правильный ответ с первой попытки,
  ошибки не наказываются.

Ещё наборы: **Хайваннар** (домашние животные) и буквы **А, Ә, И** (первая буква слова выделена красным).
Во всех наборах есть режимы:

- **🧩 Лото** — поле 3×3 с буквой в центре и бледными картинками; карточки приходят по одной, ребёнок
  перетаскивает карточку на её место (или просто нажимает на картинку).
- **👂 Тыңла** — то же лото, но на карточке нет картинки: слово нужно найти на слух.
- **🃏 Пар тап** — «мемори»: открыть две карточки и найти пару; каждая открытая карточка произносит слово
  (`"settings": {"pairs": 6}` — число пар).

Набор **Минем гаиләм** (семья): әни, әти, әби, бабай, кыз, малай. Картинки животных и семьи нарисованы
в одном стиле (SVG, `tools` не нужны — это обычные файлы `.svg`).

Набор **Төсләр** (цвета): кызыл, сары, яшел, зәңгәр, ак, кара, шәмәхә, кызгылт сары, көрән, ал, соры —
капельки-персонажи (`tools/art/draw_colors.py`). Своя игра **🎈 Шарлар**: звучит цвет, ребёнок лопает шарик этого цвета
(цвет шарика берётся из поля `"color"` элемента; без него на шарике рисуется картинка — режим подходит любому набору).
`"keepColor": true` — в лото картинки не обесцвечиваются.

Настройки набора: `"letter": "А"` — буква в центре лото и подсветка первой буквы;
`"settings": {"imageFit": "cover"}` — для фото-карточек (заполняют клетку целиком); `"center": "🏡"` — эмодзи в центре лото.

## Запуск локально

Модули и `fetch` не работают через `file://`, нужен любой локальный сервер:

```bash
python -m http.server 8000
# открыть http://localhost:8000
```

(или расширение *Live Server* в VS Code).

## Публикация на GitHub Pages

1. `git push` в репозиторий.
2. *Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)`*.
3. Сайт будет на `https://<user>.github.io/uen/`. Все пути относительные, поэтому работает в подпапке.

После любых изменений поднимите `VERSION` в `sw.js` (`uen-v1` → `uen-v2`), чтобы установленные
приложения обновились.

## Озвучка

В браузерах нет татарского синтеза речи, поэтому фразы озвучиваются записями.
Откройте **`tools/recorder.html`** (через тот же сервер), запишите каждую фразу и сохраните —
файлы называются ровно так, как ожидает `pack.json` (`kuyan.wav`, `ayu.wav`…).
Положите их в `packs/heroes/audio/`. Пока записи нет, игра просто показывает текст.

**Синтез вместо записи (Windows).** Если в Windows установлен татарский голос (Silero, RHVoice…),
запустите двойным щелчком **`tools/make-voice.bat`** — он создаст недостающие WAV-файлы для всех наборов
этим голосом. Уже существующие файлы (ваши записи) не трогает. Опции:
`make-voice.bat -List` (список голосов), `-Voice silero`, `-Rate -2` (медленнее), `-Force` (перезаписать).
Голоса, зарегистрированные только для 32-битных программ, скрипт находит сам.

Запасной вариант: в `js/core/storage.js` можно включить `ruVoiceFallback: true` — тогда фразы читает русский
голос (с плохим произношением ә, ө, ү, ң — для детей не рекомендуется).

## Структура

```
index.html            главная: список всех наборов
play.html             «оболочка» игры: ?pack=heroes&mode=quiz
sw.js                 service worker (офлайн, кэш всех наборов)
manifest.webmanifest  PWA
css/style.css         общий стиль + анимации прилагательных (.anim-*)
js/
  hub.js, play.js, pwa.js
  core/               общее для всех игр
    dom.js            h(), shuffle, sample, wait
    audio.js          speak(item): запись → татарский TTS → (опц.) русский TTS; звуки-эффекты без файлов
    packs.js          загрузка и нормализация наборов
    storage.js        настройки и звёзды (localStorage)
    fx.js, widgets.js эффекты, фраза с подсветкой слов, иконки
  modes/              типы игр (learn, quiz) + реестр index.js
packs/
  index.json          список наборов
  heroes/             один набор = папка: pack.json + img/ + audio/
tools/recorder.html   запись озвучки
```

### Новый набор слов (без программирования)

1. Создайте папку `packs/<id>/` с `img/` и `audio/`.
2. Напишите `pack.json` (как в `packs/heroes/pack.json`). Поля элемента:
   - `id` — латиницей, `image`, `audio` — пути внутри папки набора;
   - `words` — слова с переводом и ролью (`adj` подсвечивается оранжевым, `noun` — тёмным);
     или просто `"tt": "алма", "ru": "яблоко"` для одного слова;
   - `anim` — `bounce | tremble | strong | tiny | pretty | sly | angry | big` (или добавьте свою в CSS).
3. Добавьте `<id>` в `packs/index.json`. Готово — набор появится на главной со всеми режимами из `modes`.

### Новый тип игры

Создайте `js/modes/<id>.js`:

```js
export default {
  id: 'memory', title: { tt: 'Пар тап', ru: 'Найди пару' }, emoji: '🃏', minItems: 3,
  start({ pack, stage, ui, finish }) {
    // рисуем в stage, ui.speak(item), ui.progress(i, n), ui.addStar(el)
    // по окончании: finish({ stars, total })
    return () => { /* очистка */ };
  },
};
```

Зарегистрируйте в `js/modes/index.js`, добавьте в `SHELL` в `sw.js` и в `"modes"` нужных наборов.
